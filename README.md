# Gold ML Project

A beginner-friendly repository for downloading historical gold and market data from Yahoo Finance and training simple machine learning models to predict gold prices.

## Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Download market data
python scripts/download_market_data.py

# 3. Open the starter notebook
jupyter notebook notebooks/gold_ml_starter.ipynb
```

## Starter Notebook

[`notebooks/gold_ml_starter.ipynb`](notebooks/gold_ml_starter.ipynb) walks you through loading the unified CSV, exploratory data analysis (EDA), feature engineering, training a Linear Regression and Decision Tree model, and visualising predictions vs. actuals — with beginner-friendly comments throughout.
