# Gold ML Project — End-to-End Data Pipeline & ML Starter

This repository contains everything you need to **download historical market data from Yahoo Finance**, explore it, and build a machine-learning model to predict gold prices.

## 🚀 Quick-Start Guide (Step by Step)

### Step 1 — Install Python

Make sure you have **Python 3.9 or newer** installed.  
Check by running:
```bash
python --version
```

---

### Step 2 — Clone or Download This Repo

```bash
git clone https://github.com/danishgondal174-spec/BLANK.git
cd BLANK
```

---

### Step 3 — Install Requirements

```bash
pip install -r requirements.txt
```

This installs:
| Package | What it does |
|---------|-------------|
| `yfinance` | Downloads market data from Yahoo Finance |
| `pandas` | Data manipulation |
| `numpy` | Numerical operations |
| `scikit-learn` | Machine learning models |
| `matplotlib` / `seaborn` | Charts and plots |
| `ta` | Technical indicators (RSI, MACD, etc.) |
| `jupyter` / `notebook` | Interactive notebooks |

---

### Step 4 — Download Market Data

```bash
python scripts/download_market_data.py
```

This fetches and merges historical data for:
- **Gold** futures (`GC=F`)
- **S&P 500** index (`^GSPC`)
- **US Dollar Index** (`DX-Y.NYB`)
- **Crude Oil** futures (`CL=F`)
- **10-Year Treasury Yield** (`^TNX`)

The default date range is **2010-01-01 to 2024-12-31**.  
To use a custom range:
```bash
python scripts/download_market_data.py --start 2015-01-01 --end 2023-12-31
```

Output is saved to `data/yahoo_market_data.csv`.

---

### Step 5 — Verify the CSV

Open `data/yahoo_market_data.csv` in Excel or inspect it in the terminal:
```bash
python -c "
import pandas as pd
df = pd.read_csv('data/yahoo_market_data.csv', index_col='Date', parse_dates=True)
print(df.shape)
print(df.columns.tolist())
print(df.head())
"
```

You should see columns like:
```
gold_Open, gold_High, gold_Low, gold_Close, gold_Volume,
sp500_Open, sp500_Close, ..., dxy_Close, oil_Close, tnx_Close
```

---

### Step 6 — Open the Starter Notebook

```bash
jupyter notebook
```

In the browser, navigate to `notebooks/` and open `01_eda_and_ml_starter.ipynb`.

The notebook guides you through:
1. Loading and inspecting the CSV
2. Exploratory Data Analysis (EDA) with charts
3. Creating the **target variable** (next-day gold return)
4. Building **features** (returns, moving averages, RSI, lag features)
5. Training a **baseline ML model** (Random Forest)
6. Evaluating model performance

## 🧠 ML Development Ideas

After you have the dataset working, consider:

- **Target variable options:**
  - Next-day gold Close price
  - Next-day log return: `log(gold_Close_t+1 / gold_Close_t)`
  - Binary direction: 1 if price goes up, 0 if down

- **Feature ideas:**
  - Rolling averages (5-day, 20-day, 50-day)
  - RSI, MACD, Bollinger Bands
  - Cross-asset correlations (gold vs USD, gold vs oil)
  - Lag features (price/return from N days ago)

- **Models to try:**
  - Linear Regression (baseline)
  - Random Forest / Gradient Boosting (XGBoost, LightGBM)
  - LSTM / time-series deep learning

## ❓ Troubleshooting

| Problem | Solution |
|---------|----------|
| `ModuleNotFoundError: yfinance` | Run `pip install -r requirements.txt` |
| `No data returned` warning | Check internet connection; try a shorter date range |
| Empty CSV | Ensure `data/` folder exists; the script creates it automatically |
| Jupyter not found | Run `pip install notebook` then retry |
