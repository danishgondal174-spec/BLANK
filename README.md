# Gold ML Project

Automatically download historical market data from Yahoo Finance and build a merged CSV dataset for a gold price machine-learning pipeline.

---

## What this project does

A single Python script fetches daily price history for:

| Asset | Yahoo Ticker | Notes |
|---|---|---|
| Gold Futures | `GC=F` | Primary target variable |
| S&P 500 | `^GSPC` | Equity market signal |
| Nasdaq Composite | `^IXIC` | Tech / risk-on signal |
| Dollar Index | `DX-Y.NYB` | Inverse gold relationship |
| Dollar Index ETF (proxy) | `UUP` | Fallback if DX-Y.NYB unavailable |
| WTI Crude Oil | `CL=F` | Commodity correlation |
| US 10-Year Treasury Yield | `^TNX` | Macro / rates signal |

All series are outer-joined on the date index and saved as `data/yahoo_market_data.csv`.

---

## Prerequisites

- **Python 3.8 or newer** — [download here](https://www.python.org/downloads/)
- An internet connection (the script calls Yahoo Finance APIs at runtime)

---

## Step-by-step setup

### Step 1 — Clone or download this repository

```bash
git clone https://github.com/danishgondal174-spec/BLANK.git
cd BLANK
```

Or download the ZIP from the GitHub page and unzip it.

---

### Step 2 — Install Python dependencies

Open a terminal (Command Prompt / PowerShell on Windows, Terminal on Mac/Linux) inside the project folder and run:

```bash
pip install -r requirements.txt
```

This installs `pandas`, `yfinance`, and `requests`.

> **Tip:** If you have multiple Python versions, use `pip3` instead of `pip`.

---

### Step 3 — Run the download script

```bash
python scripts/download_market_data.py
```

The script will print progress for each ticker and a final summary, for example:

## Optional: change date range or interval

```bash
# Custom date range
python scripts/download_market_data.py --start 2015-01-01 --end 2024-12-31

# Weekly bars instead of daily
python scripts/download_market_data.py --interval 1wk

# Save to a different file
python scripts/download_market_data.py --output my_data/custom_output.csv
```

Run `python scripts/download_market_data.py --help` for all options.

## Troubleshooting

### "I can't find the Download button on Yahoo Finance website"
You don't need it — the script downloads data automatically via the `yfinance` Python library.  
Just follow the steps above.

### "No data returned" for a ticker
Some tickers (especially `DX-Y.NYB` for the Dollar Index) are occasionally unavailable on Yahoo Finance.  
The script automatically falls back to the `UUP` ETF as a Dollar Index proxy.  
If other tickers fail, re-run the script — Yahoo Finance sometimes rate-limits or returns empty responses on the first attempt.

### "Rate limit / too many requests" error
Yahoo Finance has informal rate limits. Wait 30–60 seconds and try again.  
If the problem persists, add `--start` / `--end` to narrow the date range.

### "Module not found: yfinance" (or pandas)
Run `pip install -r requirements.txt` again and make sure you are using the correct Python environment.

### Script crashes immediately
Make sure Python 3.8+ is installed:
```bash
python --version
```
Make sure you are running the script from the **project root folder** (the `BLANK` directory), not from inside `scripts/`.
